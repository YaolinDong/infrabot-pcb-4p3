# R8 制造资料

- PCB 下单文件：`Gerber.zip`，原生 EDA 导出，与冻结 R8 制造包的字节一致。
- 完整器件清单：`BOM.csv`，105 颗/板。
- 完整坐标：`CPL.csv`，同一组 105 个器件，单位 mm，TOP（`T`）；原点为 PCB 左下角，旋转采用原生封装角度约定。
- 文件及源工程校验：`manifest.json`；运行仓库根目录的 `python3 -B tools/verify.py`。

板尺寸 X=100、Y=130 mm，名义厚度 1.6 mm。层序从上到下：

1. `Gerber_TopLayer.GTL`：顶层信号。
2. `Gerber_InnerLayer1.G1`：地参考。
3. `Gerber_InnerLayer2.G2`：电源分区。
4. `Gerber_BottomLayer.GBL`：底层信号。

采用普通四层板工艺，没有下达受控阻抗要求。实际介质厚度、表面处理、工艺能力和数量由制造订单确定；本公开版没有保留原作者的 5 块订单数量或个人自焊筛选。

跟随 GTS/GBS 阻焊文件制作；过孔为普通机械镀通孔。共 214 个过孔，其中一个钻孔 Ø0.20 mm/焊盘 Ø0.45 mm，其余钻孔 Ø0.30/0.3048 mm。需核对实际板厂工艺。没有盲埋孔或树脂/铜填孔要求。

`Drill_PTH_Through.DRL` 已含元件镀通孔和过孔；`Drill_PTH_Through_Via.DRL` 是过孔子集，不能重复当成额外钻孔。另有 NPTH 文件。钢网为顶面，所有器件在顶面；并非所有器件都是纯 SMT。

**LED2 必须先成形引脚再插装。** 工厂未确认这道工序时，不能把完整 BOM 自动匹配成功视为装配完成。若选择自行焊接任何器件，须从工厂 BOM/CPL 同时排除，完整设计 BOM 保持不变。元件极性、Pin 1 和厂商坐标解释仍需在订单预览核对。

这些文件是工程参考设计的制造输入，不代表已经完成供应商 DFM、实物配合、EMC、温升或整机功能验证。原生 DRC 证据的范围见 `../../verification/README.md`。
