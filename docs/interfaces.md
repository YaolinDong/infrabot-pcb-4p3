# 接口、供电与软件边界

本页坐标方向以元件面朝向观察者、RJ45/USB 位于上侧为准。完整引脚网络以原理图和 `verification/expected-netlist.json` 为准。

## 供电

- J1 DC 输入范围按本设计使用 **6–12 V**；不得接机械臂常见的 24 V 电源。
- 主 5 V 经开关供给负载，底板另产生 3.3 V；屏幕经核心板的 FPC 支路供电。
- 只用 USB 时，二极管、开关和线缆压降可能使 CAN 收发器的 +5V 接近或低于供电下限。机械臂 CAN 工作使用 DC 供电。
- SW1 关闭主电源不等于所有节点完全断电；USB-UART 的 I/O 可能存在受电阻限制的反向供电路径。
- 核心板/屏幕最大负载电流、稳压器温升和电源瞬态仍需实测；BOM 和静态 DRC 不提供这些测试结论。

## CAN、SWD 与通信

- J5 CAN 顶边端子：正面从左到右 **GND、CANL、CANH**；编号分别为 3、2、1。总线接 H、L、GND，并按实际拓扑在两端配置终端电阻。
- J4 是 120 Ω 终端电阻跳帽，根据板子是否位于总线端点决定是否短接。
- J6 SWD 下侧弯头排针：正面从左到右 **1=3V3/Vref、2=SWDIO、3=GND、4=SWCLK、5=NRST**。方焊盘为 1 脚。3V3/Vref 是调试电压参考，是否供电须按下载器和系统连接方式确定。
- J3 为 USB-UART；RJ45 与 LAN8720A/RMII 链路相连。50 MHz 有源时钟经分配器分别送往 PHY 和 MAC，不能按 PHY 输出时钟的旧方案配置硬件。

## 控制输入和状态灯

- SW3 / STOP / KEY1：PA0，高电平有效。
- SW4 / RESUME / KEY2：PC13，高电平有效。
- SW2 / RESET：拉低 NRST，复位 MCU/PHY。
- LED2 红、绿、蓝分别由 PH10、PH11、PH12 控制，低电平亮，经开漏驱动连接共阳 LED。

STOP/RESUME 是供软件使用的普通输入。本板没有独立的安全急停执行链；按键名称不保证特定固件的停止、持续禁止使能或故障处理行为。

## 屏幕与外部软件

使用兼容 4.3 寸模块，参考参数 GL043056B0、480×272。显示与触摸直接连接核心板 40Pin FPC；底板没有 J7 并联 RGB/触摸支线。

使用与核心板及显示转接模块配套的 FPC。核心板扩展口 39/40 脚为 5 V、所参考屏幕扩展口 1/2 脚为 5 V，不能按同号针脚自行接线，也不要误插裸 LCD 的原始接口。配套线型号、触点面、1 脚方向和模块版本应在实际装配中确认。

本仓库不包含固件、SDK 或可直接运行的机械臂程序。GPIO 功能、RMII 时钟、LCD 时序、触摸控制器和 CAN 协议须由选用的软件实现；原理图公开了硬件连接。外部固件和外壳如另外发布，应注明对应的硬件 R8 版本。
