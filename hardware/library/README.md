# LED2 成形脚封装和模型

适用器件：MHLA5319URGBDWT / C417349。PCB 采用项目自定义的 `INFRABOT_LED_RGB5_STAGGER_P1.27_D0.90_R6`；R8 保留这一封装，名称中的 R6 表示首次引入版本。

- 引脚局部 X：1=+1.905、2=+0.635、3=−0.635、4=−1.905 mm。
- 引脚局部 Y：1/3=−0.90 mm，2/4=+0.90 mm。
- 孔径 0.90 mm，焊盘直径 1.50 mm。
- 1=R 阴极，2=共阳，3=G 阴极，4=B 阴极。

文件：`LED2_R6.efoo` 是原生封装；`LED2_R6_formed.step` 是成形脚装配模型；`LED2_R6_model-binding.json` 保存模型变换参数（mil）。模型采用树脂底部距板面 4 mm 的示意高度，不能作为厂商规定的唯一成形高度。

公开 PCB 中清除了原作者机器上的绝对模型路径，因此 LED2 模型可能需要重新关联。将本目录 STEP 导入自己的 EDA 模型库，按变换参数关联 LED2，并目视确认脚位。其余器件的库模型取决于所用 EDA 库；没有随本仓库复制整套厂商/平台 3D 库。

可选重建：安装与环境匹配的 `cadquery-ocp` 后运行 `python3 tools/build_led2_step.py`。原模型生成环境为 Python 3.12、cadquery-ocp 8.0.1.1.0。该依赖仅用于重建模型，不属于普通离线核验的依赖。
