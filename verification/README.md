# 验证范围

本目录保存 R8 电路与当前原理图整理草稿的检查记录。项目仍为开发草稿；校验通过不表示已经批准公开发布或下单生产。

## 当前核验

`python3 -B tools/verify.py` 只读核对交付文件哈希、原理图/PCB 引脚网络、完整 BOM/CPL 的位号/数量/位置/角度及装配面，以及 Gerber ZIP 的必需图层。

原理图整理前后，105 个器件、338 个已分配引脚网络和 475 个 PCB 器件焊盘保持一致。电路符号的位置和朝向、局部连线、网标和功能分区作了整理；型号、封装、BOM 属性及嵌入符号/封装库未变。EDA 原生网表也逐项核对了全部 338 个连接。

PCB 仅同步了 EDA 重新分配的 104 个 Channel ID 关联字段，几何、网络、焊盘、元件位置/角度及原有中文作者丝印均未改变。Gerber、完整 BOM 和 CPL 的字节保持一致。同步后，隔离工程的原生严格 PCB DRC 为 0 错误。

原理图 ERC 为 0 电气错误；仍有一组 ATTRMATCHCODE，包含原有 SW1、LED2 两个有意修改的封装提示。没有扩大这些例外的适用范围。

公开副本最初清除了 LED2 的作者本机模型路径，仍保留 STEP 与变换参数；该历史改动只影响模型关联。当前整理记录见 `schematic-layout-review.json`，公开与源工程关系见 `public-export.json`。

随后进行了原理图文字避让修正：调整网标、R13/R15 的原理图位置及五组局部连线路径，并修正 PDF 中引脚编号的基线、USB-C 未连接引脚编号及 RJ45 符号内的文字位置。本次 PCB 文件及 Gerber/BOM/CPL 均保持逐字节一致。六页 PDF 已逐页查看，1027 项图中文字均可提取；文字与外部连线或符号引脚线、文字之间的重叠，以及不同网络穿过引脚线的情况，几何检查结果均为 0。检查方法、覆盖范围和结果见 `schematic-text-review.json`；可用 `/usr/bin/python3 -B tools/check_schematic_text.py` 重跑。

## 仍需实物或制造核验

- LED2 交错脚成形及实际插装工序。
- 16 mm 铜柱下屏幕、核心板、配对连接器和外壳的实物配合。
- 实际板厂叠层、表面处理、最小钻孔能力与供应商 DFM。
- 负载电流、温升、整机时序和 EMC。

这些事项不由离线脚本或文件哈希证明。原理图排版工具也不能替代电路设计审查。
